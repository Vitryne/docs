Este repositório centraliza a documentação da plataforma Vitryne, servindo como fonte oficial de consulta para desenvolvimento, manutenção e evolução do sistema.

Aqui estão documentados os requisitos, regras de negócio, arquitetura, decisões técnicas, fluxos, integrações e demais artefatos relacionados ao projeto.
